### 1.3 🔴 確定壞掉：頁尾 X 連結

- **現象**：每一期頁尾 `<a href="@ED_Ultrasounder">X</a>`，瀏覽器會解析成 `/er-cardio-weekly/2026-wNN/@ED_Ultrasounder` → 404。
- **根因**：`themes/hallmark/layouts/partials/footer.html` 第 7 行 `{{ with site.Params.twitter }}<a href="{{ . }}">X</a>{{ end }}` 直接把參數當網址；而 `config/_default/params.toml` 第 5 行 `twitter = "@ED_Ultrasounder"` 是 handle 格式（給 Twitter card meta 用的寫法）。
- **影響**：不只週報，所有用 hallmark footer 的頁面都中。
- **建議修法（網站 repo，本 PR 未動）**：`params.twitter` 全站只有這個 footer 在用（已 grep `layouts/`、`themes/hallmark/`），最小改法是把 `params.toml` 改成 `twitter = "https://x.com/ED_Ultrasounder"`；或模板改成 `https://x.com/{{ strings.TrimPrefix "@" . }}`。

### 1.4 🟡 圖片

- 29 期週報 **0 個 `<img>`、0 個 `figure-ecg`**——全部 case 都走 `ecg-linkout` 外連，所以沒有壞圖可言（這也代表 CLAUDE.md 的 `figure-ecg` 路徑從未被實際使用）。
- 站內資源（favicon、13 支 CSS、`ecw.js`）在 build 結果都存在。
- **缺 `og:image`**：頁面有 `<meta name="twitter:card" content="summary_large_image">`，但沒有 `og:image`／`twitter:image`。分享到 LINE／Facebook／X 時沒有預覽圖。建議在週報 single 模板加一張預設 OG 圖。
